# Theme Example

Everything on this site — header, footer, sidebar, table of contents,
prev/next links, the ⌘K search palette, and the light/dark toggle — comes
from `@sigx/ssg-theme-daisyui`. The site itself ships **zero layout code**.

## Install

```bash
pnpm add @sigx/ssg @sigx/ssg-theme-daisyui
```

## Try it

Press <kbd>⌘K</kbd> (or <kbd>Ctrl K</kbd>) to search, toggle the theme from
the header, and head into the [docs](/docs/getting-started) for the full
docs-shell experience.
