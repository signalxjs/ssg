# Configuration

Branding comes from `site` — title, nav, logo, repo, and `search` to show
the palette.

## Site config

```ts
site: {
    title: 'Theme Example',
    nav: [{ title: 'Docs', href: '/docs/getting-started' }],
    repo: 'https://github.com/signalxjs/ssg',
    search: true,
}
```
