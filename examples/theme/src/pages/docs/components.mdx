# Components

Compose `components.CommandPalette`, `PrevNext`, `TOC`, and friends in your
own layouts when the built-ins aren't enough.

## Code windows

Every fence gets the copy button; install fences get the package-manager
switcher:

```bash
npm install @sigx/ssg
```
