# Getting Started

Install the package and start the dev server:

```bash
npm install @sigx/ssg sigx
```

Drop `.mdx` or `.tsx` files into `src/pages/` and they become routes.

The sidebar on the left is **auto-generated** from each page's `category` and
`order` frontmatter — nothing in this example writes navigation by hand.
