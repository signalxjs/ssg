# Welcome

This is the **basic example** for `@sigx/ssg`. It demonstrates:

- File-based routing (this page is `src/pages/index.mdx`)
- A dynamic route with `getStaticPaths` under [/blog](/blog/first-post)
- A draft page that never reaches the production build
- A custom layout and a custom `index.html`
